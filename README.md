# Library Software Quality Management System

## Project Overview
A web-based Software Quality Management System developed for Team 8 to manage and improve the quality of Library Management Software development.

## Technologies Used
- Java
- JSP and Servlets
- MySQL
- Apache Tomcat
- Apache NetBeans

## Main Features
- Quality Planning
- Review Management
- Defect Tracking
- Corrective and Preventive Actions
- Quality Checklists
- Continuous Improvement
- Quality Dashboard and Reports

## Database
The system uses MySQL to store quality plans, reviews, defects, corrective actions, checklists, and improvement records.
